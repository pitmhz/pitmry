# (See .gitignore file at the root)

git push -u origin main

---

## .gitignore

The project must have a `.gitignore` that excludes:

- `node_modules/` — installed by pnpm at deployment time
- `.next/` — build output; regenerated by `pnpm build`
- `*.env*` — any environment files that will contain the Python script path or secrets
