# ASD-STE100 Simplified Technical English

Use ASD-STE100 principles as the primary reference for technical communication. It provides controlled natural language for technical clarity.

## Core Rules
- **One meaning per word**: Use one term for one concept. Do not switch synonyms for the same item.
- **Active voice & Direct verbs**: Prefer direct instructions: "Run the build."
- **Clear condition order**: State conditions first: "If the test fails, inspect the log."
- **Short sentences**: State one main idea per sentence.
- **Present tense**: Use simple present tense for facts and procedures. Avoid unnecessary -ing forms, nominalizations, and vague qualifiers.
- **Numbered steps**: Use numbered steps for multi-step workflows. State the expected result.
- **Preserve identifiers**: Keep code symbols, commands, file paths, and proper names exact.
