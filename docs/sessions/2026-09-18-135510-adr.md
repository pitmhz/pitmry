## Architectural Rationale / Thought Process
Agents were losing context after compaction and could not reliably discover prior work. A two-tier design preserves raw evidence while producing compact project-scoped recovery capsules. Backup-first migration and explicit readiness checks make persistence, indexing, and integrations observable instead of assumed.

## Key Decisions
Use SQLite as the canonical append-first memory ledger; create deterministic project-scoped checkpoints before compaction and restore them after; promote checkpoints to durable FTS-searchable memory; use LanceDB only as the semantic index synchronized from SQLite; require cavemem doctor --json as the single readiness contract for the dashboard and agent workflows.

## Context & Constraints
Support Codex and Claude Code, limited context windows, repeated compaction, offline local storage, and dedicated memory-navigation skills. No cloud dependency. Credentials and private blocks must be excluded from stored memory.
