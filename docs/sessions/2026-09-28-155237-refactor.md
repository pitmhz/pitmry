## Summary & Impact
Decomposed app-shell/skills-workspace/code-diff-viewer into focused modules, added a capability-aware inspector and sidebar commit-diff route, and fixed a dead diff viewer (raw text vs structured contract), a git-SHA crash, and a Windows cp1252 decode error that nulled every patch.

## Architectural Rationale / Thought Process
The diff viewer had never worked: the backend returned raw patch text while the viewer required files/hunks/lines, so it rendered an error for every commit. The endless loading was a 45-80s read caused by a stateless CanonicalStore used in nested loops (84.8M calls, 310k file opens); mtime-guarded caching brought it to a stable 1.6s. The first cache attempt silently bypassed manifest validation and was caught by pre-existing tests.

## Key Decisions
Cache the filesystem-backed store against the file's (mtime_ns, size) stamp rather than invalidating on write, because the store is a view of files that other code writes directly. Accept one stat per read to keep validation honest. Parse unified diff into the viewer's declared shape in the backend so the frontend stays a pure renderer and every entry point is fixed at once.
