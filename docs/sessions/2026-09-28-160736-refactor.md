## Summary & Impact
The canonical mirror now records a restorable state note with a stable subject key and rebuilds the projections, so a session is retrievable through pitmry context immediately instead of after a manual rebuild.

## Architectural Rationale / Thought Process
Writing a record is not the same as making it findable. The first version migrated rows and left the projection stale, so retrieval returned an older session.

## Key Decisions
Record the restore point through pitmry decision with a subject key derived from project and commit, then rebuild, in the same non-fatal step as the migration.
