## Summary & Impact
Added a Target E to the exporter that mirrors each exported session into the PITMRY canonical store via pitmry migrate-legacy, so a session recorded in Cavemem and LanceDB is also visible in the dashboard.

## Architectural Rationale / Thought Process
The exporter and the dashboard read different systems. Cavemem SQLite and LanceDB are for agent retrieval; the dashboard reads .pitmry/records/. A session could be fully exported and still be invisible, which is exactly what happened.

## Key Decisions
Made the canonical step conditional on .pitmry/manifest.json existing, scoped to the current project, and non-fatal, so it is a no-op for non-PITMRY projects and can never fail an export that already succeeded.
