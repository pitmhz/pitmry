## Summary & Impact
Redesigned the code changes widget from a cramped two-column layout into a vertically stacked architecture with 100% diff width. Added horizontally scrollable file pills with search and quick-jump select, dedicated breadcrumb bar, and comprehensive change breakdown accordions across deploys and relational inspector.

## Architectural Rationale / Thought Process
- Narrow sidebars (~450px) cannot accommodate two side-by-side columns (file list and diff viewer) without truncating paths and squeezing diff lines.
- Stacking files horizontally above a full-width diff canvas provides optimal readability and standard editor-like ergonomics (similar to VS Code / Zed tabs).
- Exposing structured commit bullet points ensures architectural decisions and changes are immediately transparent throughout the dashboard.

## Key Decisions
1. Vertically stacked diff viewer with full-width canvas and dedicated active file breadcrumb bar.
2. Horizontally scrollable file tabs strip with search filter, left/right scroll chevrons, and quick-jump select.
3. Deploy history accordions with `[N change highlights]` and `Details` toggle buttons.
4. Dedicated "What Changed (Detailed Breakdown)" card in the relational inspector panel.
